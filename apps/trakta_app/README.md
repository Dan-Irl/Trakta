# trakta_app

The Trakta Flutter app. Run `flutter` commands in this folder:

```sh
flutter run                                    # debug build on a connected phone or emulator
flutter test                                   # widget, data and l10n tests
flutter test test_screenshots --update-goldens # website and store screenshots
```

Setup, the rules for changes and the architecture are in the repository root: [README](../../README.md), [CONTRIBUTING](../../CONTRIBUTING.md) and [docs/architecture.md](../../docs/architecture.md).
